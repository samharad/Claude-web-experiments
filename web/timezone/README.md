# Timezone Converter

A quick timezone conversion tool. Enter a time and source timezone, and instantly see the equivalent time across multiple target timezones.

## Features

- Auto-detects your local timezone as the default source
- Shows conversions across commonly used timezones (ET, PT, London, Tokyo, etc.)
- Add or remove target timezones as needed
- Remembers your selected target timezones across sessions
- Shows day boundary crossings (+1 day, -1 day)
- Supports all IANA timezones via the browser's Intl API
