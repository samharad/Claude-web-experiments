# Airplane Flight Animation

An interactive flight animation tool that visualizes airplane routes between any two locations on a world map.

## Features

- Enter locations as city names (e.g., "Athens, Greece") or coordinates (e.g., "37.9838, 23.7275")
- Calculates great circle routes for realistic flight paths
- Animates an airplane icon along the route with proper rotation/bearing
- Configurable animation duration
- Uses OpenStreetMap for the base map and Nominatim for geocoding
- Saves last used locations to localStorage

## Purpose

Useful for visualizing flight paths, understanding great circle routes, or creating animated demonstrations of air travel between any two points on Earth.
