# LeetCode Problem Search

A tool to find LeetCode problems matching a description of a coding challenge.

## Features

- Describe a data structures / algorithm problem in plain language
- Uses OpenAI's GPT-4o with web search to find matching LeetCode problems
- Returns exact matches and similar problems with links
- **Does NOT reveal solutions or hints** - only provides problem titles, URLs, difficulty, and neutral descriptions

## Usage

1. Enter your OpenAI API key (stored locally in browser)
2. Describe the coding problem you're looking for
3. Click "Search LeetCode" to find matching problems

## Example Queries

- "Find two numbers in an array that add up to a target"
- "Reverse a linked list"
- "Find the longest substring without repeating characters"
- "Binary tree level order traversal"
