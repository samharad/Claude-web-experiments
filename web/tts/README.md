# Text to Speech

A web-based text-to-speech tool using OpenAI's TTS API.

## Features

- Convert text to natural-sounding speech
- Multiple voice options (Alloy, Ash, Ballad, Coral, Echo, Fable, Marin, Cedar, Nova, Onyx, Sage, Shimmer, Verse)
- Model selection: TTS-1 (fast), TTS-1-HD (quality), GPT-4o Mini TTS
- Cost calculation displayed after each request
- API key stored securely in localStorage

## Usage

1. Enter your OpenAI API key (stored locally in your browser)
2. Type or paste text into the textarea
3. Select a voice and model
4. Click "Generate Speech" to hear the audio

## Pricing

- TTS-1: $15 per 1M characters
- TTS-1-HD: $30 per 1M characters
- GPT-4o Mini TTS: $15 per 1M characters
