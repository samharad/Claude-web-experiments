# Effective Hourly Rate

Compare compensation packages by calculating and comparing effective hourly rates.

## Inputs (per offer)

- **Annual compensation** — total yearly pay
- **Hours per week** — expected working hours
- **Vacation days** — paid time off days per year
- **Holidays** — company holidays per year

## How it works

Working hours per year = ((260 − vacation − holidays) / 5) × hours per week

Effective hourly rate = annual compensation / working hours per year

## Features

- Add and remove as many comparison panels as needed
- Optional name for each offer
- "Best" badge highlights the highest effective hourly rate when comparing multiple offers
