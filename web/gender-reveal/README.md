# Gender Reveal

A balloon pop game for revealing baby gender.

## How it works

1. A single balloon appears in the center of the screen
2. Tap it to start the game - rainbow confetti bursts out
3. Balloons begin floating up from the bottom of the screen
4. Pop 10 balloons, each releasing rainbow confetti
5. On the 11th pop, ALL balloons explode in blue confetti
6. Once the confetti clears, the boy emoji fades in

## Design

- Balloons float leisurely from bottom to top with a gentle side-to-side wobble
- Uniform balloon sizes in rainbow colors
- Blue gradient background
- No instructions - discovery through interaction
